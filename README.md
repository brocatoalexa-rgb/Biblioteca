# 📚 Biblioteca Online

Applicazione web per gestire una libreria online.

## Stack
- PHP 8.2
- MongoDB
- JavaScript (XHR puro)
- HTML / CSS

## Credenziali demo
- Admin: admin / Admin123!
- Utente: registrati liberamente

## API Endpoints
| Metodo | Endpoint | Descrizione |
|--------|----------|-------------|
| GET    | /api/libri.php | Lista libri |
| POST   | /api/libri.php | Aggiungi libro |
| PUT    | /api/libri.php?id=xxx | Modifica libro |
| DELETE | /api/libri.php?id=xxx | Elimina libro |
| POST   | /api/auth.php?action=login | Login |
| POST   | /api/auth.php?action=register | Registrazione |
| GET    | /api/recensioni.php | Recensioni |
